# COVID-19 Cases by Age Analysis using Python

## 📌 Project Overview

This project explores COVID-19 case data by age group using Python. The analysis applies exploratory data analysis and descriptive statistics to examine the distribution of COVID-19 cases across different age groups.

## 🎯 Objectives

* Analyze COVID-19 cases across different age groups.
* Explore the distribution of cases using descriptive statistics.
* Calculate total cases by age group.
* Identify patterns in COVID-19 cases across different age categories.

## 📊 Dataset

* **Dataset:** `cases_age.csv`
* **Source:** Public dataset for educational and data analysis practice.

## 🛠️ Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* Matplotlib

## 🔍 Analysis Performed

* Loaded and inspected the COVID-19 dataset.
* Explored the dataset structure and variables.
* Performed descriptive statistical analysis.
* Calculated total COVID-19 cases across age groups.
* Compared case counts across different age categories.

## 📈 Age Groups Analyzed

* 0–4
* 5–11
* 12–17
* 18–29
* 30–39
* 40–49
* 50–59
* 60–69
* 70–79
* 80+

## 🔍 Key Findings

* The 30–39 age group recorded the highest total number of cases in the analysis, followed by the 18–29 age group.
* The analysis showed differences in COVID-19 case counts across age groups.
* Descriptive statistics provided an overview of the distribution and variation of cases across the dataset.
